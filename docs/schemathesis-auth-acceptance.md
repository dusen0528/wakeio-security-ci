The adopted policy is `{version:1,kind:'schemathesis-get-auth',baseUrl,authorizationEnv,identity:{path,status,jsonPointer,equals},operations:[{path,normal:{path,status,jsonPointer,equals}}]}`. CLI adds `--schemathesis-auth-policy FILE`; SDK adds `authPolicy` and `env`. Identity and normal paths are explicit same-origin GET controls. Normal assertions require exact 2xx status and JSON scalar equality; they do **not** establish full response-schema conformance. Selected generation remains GET-only and explicitly operation-bound.

The order is identity-before; for each operation anonymous-normal then authenticated-normal-before; generation; each authenticated-normal-after; identity-after. Anonymous controls require 401/403 **and absence of the protected marker**. Completion requires all controls matched and at least one completed generated case per selected operation. Controls cost `2+3N` requests, minimum total budget is `2+4N`; all attempts, response bytes and deadline use one shared budget. Generated 401/403, initial control failure, normal failure, drift, cancellation, transport or budget failure remain incomplete2. Initial failure prohibits generation. Trailing failure preserves concrete findings without establishing authenticated completion. `failOn:none` never clears incompleteness.

3. **Strict scope and immutable credential input.** Invalid policy/options, duplicate/missing operation controls, out-of-selection normal path, external/remote refs, credential header/cookie generation conflicts, wrong origin, public plaintext credential transport, inherited/accessor/proxy credentials and missing consent refuse before target traffic. Redirects are not followed, credentials are not forwarded, worker credentials/cookies cannot replace the snapshot, and response Set-Cookie cannot mutate subsequent auth. 4. **Verified TLS and bounded lifecycle.** HTTPS succeeds with an owned CA via standard process `NODE_EXTRA_CA_CERTS`, and untrusted/wrong-host TLS reaches no HTTP handler. Never disable TLS verification. Fixed worker facade to Node's pinned verified transport must enforce actual GET/operation/attempt bounds; CONNECT counts are not HTTP counts. Budget-one-below-minimum, byte caps, dropped reply, slow streaming and cancellation produce2, no request retry or redirect follow, no requests after stop, and owned child/descendant/socket cleanup. Existing selected scope limits are not widened.
5. **Evidence cannot be upgraded by numbers.** Typed auth metadata must cross-check exact policy revision/digest, selected operation identities, ordinal/control order, attempted outcomes, per-operation generated records, shared attempt counts and completion. Missing/duplicate/unknown controls, forged matched markers with contradictory steps, omitted operation, malformed enums, wrong worker identity/digest, secret extra fields and present malformed/absent-required metadata are controlled rejection or incomplete2, never clean.
